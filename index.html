Install on Phone

Open MiLeo Sync, the mobile companion, on Android or iPhone. Keep your phone and Desktop on the same Wi-Fi network, and keep the Desktop app running for library access and local photo synchronization.

Scan with your phone camera, or copy this URL. Pairing codes are single-use and expire when the countdown ends. Already paired phones can open the URL without a new code.

The local HTTPS certificate is self-signed. Compare the certificate fingerprint with the one below before trusting it. A browser warning bypass alone may not allow PWA installation or offline support; your phone must trust the certificate. Otherwise, use the mobile site in the browser.

Android

Open the URL in Chrome, then choose Install app or Add to Home screen from its menu. An Install button appears on the phone when the browser supports it.

iPhone / iPad

Open the URL in Safari, tap Share, then Add to Home Screen. If offered, enable Open as Web App, then tap Add.

This installs the existing mobile web companion, not an App Store or APK download. The app shell can work offline when supported, but viewing photos, pairing, sign-in and sync require a connection to this Desktop. iPhone supports browsing and manual uploads; phone-folder linking requires a compatible Android browser.
